# Avocado Market Analysis

Files for the avocado market assignment:

- `Avocado_Market_Analysis.ipynb` — Python notebook used to verify memo figures
- `HAB-FlatFile-Weekly-2025.csv` — 2025 source data
- `HAB-FlatFile-Weekly-2026-P1-P8.csv` — 2026 source data

## Comparison method
The 2026 file contains 32 weekly periods through August 9, 2026, so the notebook compares Periods 1–32 in both years and filters to `Geography == "Total U.S."`.

## Main verified figures
- Total U.S. volume: 13.6%
- Volume-weighted ASP: -19.1%
- Conventional volume: 14.5%
- Organic volume: -0.7%
